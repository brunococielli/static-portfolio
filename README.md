## Static Portfolio
A personal static portfolio website built to showcase projects, contact information and things I like in a clean and accessible way.  
The project focuses on frontend fundamentals, responsive layout, and clear presentation of work.

---

### Features
- Project showcase with source code links
- Clean, minimal UI with custom styling
- Responsive layout for desktop and mobile
- Simple navigation and smooth user experience

---

### Tech Stack
- JavaScript
- HTML
- CSS
- GitHub Pages (deployment)

---

### How It Works
- The portfolio is fully static and runs entirely in the browser
- Each project card links to the source code on GitHub
- Styling is handled with custom CSS, focusing on clarity and consistency
- JavaScript is used for interactions and navigation behavior
- The site is deployed using GitHub Pages for easy access and sharing
